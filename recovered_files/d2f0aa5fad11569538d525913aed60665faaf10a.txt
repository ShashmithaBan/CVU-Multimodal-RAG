# Backend Evaluation Diagram Usage

## Generating Evaluation Diagrams

After running the full video evaluation, a bar chart diagram of the main evaluation metrics will be automatically generated and saved as an image file in the outputs folder (e.g., `outputs/<video_id>_evaluation_diagram.png`).

### How to Run

```bash
python full_video_evaluation.py --video-id <VIDEO_ID>
```

- The diagram will be saved as `outputs/<VIDEO_ID>_evaluation_diagram.png`.
- You can open this image to visually inspect the evaluation results.

## Requirements
- `matplotlib` is required for diagram generation (already included in requirements.txt).

## Example Output
- Bar chart showing OCR Coverage, Code Detection, Retrieval Success, Extraction Success, Consistency, and Overall Score.

---
For more details, see the `plot_evaluation_results` method in `full_video_evaluation.py`.
